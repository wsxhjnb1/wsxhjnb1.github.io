02 / ENGINEERING

Selected systems work

Implementations with measured, explicitly scoped results.

01

CUDA / vLLM

OrbitCall

An opt-in vLLM 0.29 plugin for scoring finite JSON key-order tool-call families. It preserves native LM-head projection shapes and complete JSON/EOS likelihoods while reducing normalization, ranking and CPU transfer.

1.08× complete two-round Agent speedup

Qwen2.5-3B · DGX Spark (GB10) · six paired blocks · eight fixed workflows · versus native full scoring.

Code ↗Measured study ↗
02

GPU KERNELS

Attention decoding with quantized KV caches

Fused on-the-fly KV dequantization, attention scoring, online softmax and value accumulation. Packed K/V are reconstructed in registers, avoiding full-precision KV materialization in GPU memory.

40% faster inference in the measured setup

Llama 2 7B · one NVIDIA H100 · versus a Hugging Face implementation.
